# Show Me

Explain the current topic visually, with little prose and no preamble. Pick the smallest
view that makes the point: pseudocode, a call tree, a component tree, a shallow annotated
file tree, a Mermaid diagram, or a `diff` of any of those when the point is what changes.
Show a whole code block only when most of it is new or order and ownership matter.

For UI, layout, or a concept too dense for Mermaid, write one focused HTML file in the
product's own look, with real labels. Then open it for the user.

Put each visual next to the sentence it supports. Keep only the calls, files, and states the
question needs.
