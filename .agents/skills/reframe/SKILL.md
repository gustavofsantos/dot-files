# Reframe

Your last message didn't land. Rewrite it for a reader with no joint attention on the code. Same findings, new presentation: this is a translation, not a new analysis.

1. **Extract** the question being answered, the bottom line, and the 3–5 load-bearing claims. Everything else is optional.
2. **Pick the shape** that fits the content:
   - causal chain or sequence → numbered beats, one claim per beat, each understandable on its own
   - comparison or options → table
   - structure or flow → small ASCII diagram
   - abstract mechanism → one concrete case walked end to end
3. **Write** the bottom line first, then the shape, then the so-what: what I should decide or do. Code locations go in a trailing "Where:" list.

Plain register: no hooks, emojis, hashtags, or social-media phrasing. Keep caveats that change a decision; drop the rest. Mark uncertainty in one clause. Be shorter than the original. Apply way-of-communication.
